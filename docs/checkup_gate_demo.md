# Checkup gate demo — `refund` dev unit

[#833](https://github.com/promptdriven/pdd/issues/833) showcase on **`demo/checkup-gate-showcase`**.

## Principle

| Hand-crafted | Generated by PDD |
|--------------|------------------|
| `prompts/refund_python.prompt` | `src/refund.py`, `tests/`, `examples/`, `user_stories/`, evidence manifests |

## Prerequisites

```bash
git checkout demo/checkup-gate-showcase
pip install -e ".[dev]"
pdd setup
export PDD_FORCE=1
cd examples/checkup_gate_demo
```

## Showcase commands

```bash
pdd sync refund --evidence
pdd checkup contract check prompts/
pdd checkup coverage prompts/
pdd checkup gate refund --json
```

Script: `./run_demo.sh` (set `CLEAN=1` to remove prior generated files first).

## Explicit generate path (optional)

If you prefer separate steps before gate:

```bash
pdd generate prompts/refund_python.prompt --output src/refund.py --evidence
pdd test --manual prompts/refund_python.prompt src/refund.py --evidence
pdd detect --stories --evidence
pdd sync refund --evidence
pdd checkup contract check prompts/
pdd checkup coverage prompts/
pdd checkup gate refund --json
```
